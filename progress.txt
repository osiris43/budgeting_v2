## Codebase Patterns
- `create_app()` calls `_check_ollama()` which requires a running Ollama instance — tests must patch `app._check_ollama` and set `DATABASE_URL=sqlite://` env var before importing `create_app`
- Use `setup.cfg` with `[flake8] max-line-length = 120` and `extend-ignore = E203` to match existing code style (pyproject.toml sets ruff line-length=100, but many lines are up to ~120)
- CLI commands are registered via `register_cli(app)` in `app/cli.py` — test with `app.test_cli_runner(mix_stderr=False)`
- Test isolation: use an autouse fixture that drops/recreates all tables between tests (savepoints don't work reliably with SQLite in-memory)
- Amounts are stored as integer cents (`amount_cents`); positive = expense, negative = credit/refund
- `MerchantRule.pattern` is a unique column — cannot insert duplicate patterns in tests
